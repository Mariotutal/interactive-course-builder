# interactive-course-builder

A reusable **Agent Skill** that turns a learning request into a rigorous, visual and interactive course on any subject. A learning request covers the topic, goals, learner profile, language, time and practice resources. The output is a validated static web app that works offline, with progress export and import, plus Markdown.

The teaching method, content contract and interaction patterns come from an audit of an existing course (see `docs/AUDIT.md`). None of that course's subject matter or personal setup is part of the package.

```
learning-tool/
  skills/interactive-course-builder/   ← the skill (install this folder)
    SKILL.md                            workflow (loaded when the skill is used)
    references/                         pedagogy, input contract, lesson contract, activities, evidence, quality rubric
    assets/runtime/                     offline renderer: app, 13 interaction patterns, safe expression evaluator, i18n (en, es), CSS
    assets/templates/                   example learning request + a valid one-lesson starter course
    scripts/lk.mjs                      deterministic CLI: check-request, init, validate, build, coverage
  examples/                             courses generated by fresh agents using only the skill
  tests/run-tests.mjs                   functional tests for the CLI, validator, builder and evaluator
  docs/                                 audit, architecture decision, evaluation, adding a subject, progress
```

## Requirements

- Node.js 18 or later (tested with 22.22). No npm packages.
- A modern browser to view the generated courses.
- An agent host that supports Agent Skills to author courses: Claude Code, or another host implementing https://agentskills.io/specification.

## Install

### Claude Code

Personal install, available in all your projects:

```bash
mkdir -p ~/.claude/skills && cp -R skills/interactive-course-builder ~/.claude/skills/
```

Project install, for one repository only:

```bash
mkdir -p .claude/skills && cp -R /path/to/learning-tool/skills/interactive-course-builder .claude/skills/
```

Claude Code picks up changes inside existing skill directories without a restart. If you created the top-level skills directory during a running session, run `/reload-skills`.

### Other Agent Skills hosts

Copy `skills/interactive-course-builder/` into the folder your host scans for skills. The frontmatter uses only fields from the open specification. Hosts other than Claude Code have not been tested.

## Use

Ask for a course in plain language. The skill activates from its description:

> Build me a course on reading nutrition labels critically, in Portuguese, for a nurse with no statistics background; 3 hours in 20-minute sessions.

You can also invoke it explicitly in Claude Code with `/interactive-course-builder <request>`.

The agent writes `request.json`, designs the outcomes, researches sources, writes the lessons, runs the validator and builder, checks the result, and reports what it verified and what it did not.

### Using the CLI directly

```bash
S=skills/interactive-course-builder/scripts/lk.mjs
node $S check-request my-request.json        # defaults, unknowns, blocking gaps
node $S init my-request.json my-course       # course.json from the request (no placeholder lessons)
node $S validate my-course                   # contract checks: lesson functions, outcome coverage, HTML safety, activity configs
node $S build my-course                      # → my-course/site/index.html, my-course/markdown/, my-course/COVERAGE.md
node $S build my-course --out /path/to/site   # site elsewhere; markdown/ and COVERAGE.md still go inside my-course/
node $S coverage my-course                   # outcome → teaching → assessment matrix
```

`build` deletes and rewrites its output directories, so it refuses any output that is the course folder, one of its parents, your home directory or the filesystem root, or a non-empty folder it did not create. It marks the folders it creates with a `.lk-build` file.

Open `my-course/site/index.html` directly. It needs no server and no network; external links in the references are the only exception. If a browser restricts local files, serve the folder with any static server:

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory my-course/site
```

## Learner data

Progress, answers and notes stay in the browser's `localStorage`, under `lk:<course-id>:v1`. The Progress page exports and imports JSON, exports notes to Markdown, and resets the course.

Imports are validated field by field before anything is replaced: files from another course, or with malformed structure, are refused, and malformed individual entries are dropped and counted. If the data stored in the browser is damaged, the course starts clean, keeps the damaged data under `lk:<course-id>:v1:damaged`, and shows a notice. When a course is rebuilt, answers to questions or activities whose content changed are discarded and reported, so stale results are never reused.

## Remove

Delete the installed directory:

```bash
rm -r ~/.claude/skills/interactive-course-builder      # or .claude/skills/interactive-course-builder in a project
```

Generated courses are standalone folders and are not affected.

## Test

```bash
node tests/run-tests.mjs
```

`docs/EVALUATION.md` describes the browser checks and the evaluation of the three example subjects.
